# Creative Templates

Reusable layout templates for static and short-form video ads, built against
[[media/brand-pack-2-4]]'s type and colour rules, so [[sops/ad-copywriter]]
and [[sops/content-planner]] are not rebuilding layout decisions for every
new piece of copy or script.

Templates exist for: single-product static ad, before-and-after split-screen,
physician-explainer lower-third, and 21-nights-series episode card (see
[[wiki/the-21-nights-series]]). No dedicated template yet exists for the
comparison format described in [[wiki/competitor-frame]], which is currently
built ad hoc each time that format runs, an open gap worth closing once the
storefront's compare page is live per [[projects/fill-the-proof-pages]].

Every new template addition should be checked against
[[media/brand-pack-2-4]] before use, and any claim-bearing text baked into a
template image (not just the caption) still needs a
[[sops/compliance-auditor]] pass before that template goes into rotation.
