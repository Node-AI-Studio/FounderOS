# Approved Product Photography

The set of product photography currently cleared for use in paid and organic
creative, covering [[products/helight-sleep]], [[products/helight-kidzzz]],
[[products/helight-nightlight]] and [[products/sleep-two-pack]] from multiple
angles, on-nightstand and isolated-product shots.

[[products/helight-nightlight]]'s current photography set should not be used
in any new paid creative while the SKU is out of stock, per
[[sops/store-auditor]]'s standing flag; using it risks driving traffic to an
unavailable product.

[[sops/ad-copywriter]] and [[sops/content-planner]] pull from this set rather
than commissioning new photography per campaign, to keep visual consistency
across [[wiki/format-playbook]]'s formats. Any format requiring lifestyle
photography beyond this set (a specific audience lane's setting, a specific
holiday context) gets flagged to [[people/operations-assistant]] as a gap
rather than filled with an unapproved stock image.

See [[media/brand-pack-2-4]] for the colour and layout rules this photography
set is shot to match, and [[wiki/format-playbook]] for which formats draw on
which shots most heavily.
