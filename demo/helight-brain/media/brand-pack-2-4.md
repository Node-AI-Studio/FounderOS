# Brand Pack 2.4

Current version of Helight's brand asset pack: logo files, colour values,
typography specification and usage rules for both the DTC storefront and paid
creative.

Version 2.4 is the version every active pillar should be pulling from; any
asset older than this version found in a live campaign or on-site placement
should be flagged by [[sops/store-auditor]] or [[sops/content-planner]] for
replacement rather than assumed to be equivalent.

The pack does not currently include dedicated templates for the retail
placements at [[companies/ulta-beauty]] or [[companies/goop]], which use
retailer-provided layouts rather than Helight's own; that gap is tracked as
open rather than resolved.

Related: [[media/approved-product-photography]], [[media/templates]], and
[[people/operations-assistant]], the de facto owner of brand-asset hygiene
until a dedicated agent covers this ground.
