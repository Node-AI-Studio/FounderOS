# Earned Media Index

## What it says

Indexes Helight's earned media coverage across five outlets: Bustle, The
Daily Beast, mindbodygreen, Sleep Review, and Glossy. Coverage ranges from
lifestyle press (Bustle, Glossy) to industry-trade press (Sleep Review) to
general-interest media (The Daily Beast, mindbodygreen).

## Date

Ongoing; this index is updated as new coverage lands rather than tied to a
single date.

## Which claims it supports

Supports "as seen in" style credibility lines in ad copy and on-site
badging, and is the reference list [[sops/evidence-curator]] checks against
before adding a new outlet logo anywhere on the storefront. Indexed
alongside the four awards in [[wiki/awards-and-press]].

[[sops/ai-answer-optimizer]] also checks this index when auditing whether
Helight's earned coverage is legible to an AI answer engine crawling news
mentions, not only whether the coverage exists.
