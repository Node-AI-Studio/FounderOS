# Format Playbook

Nine content formats in active rotation, each suited to particular angles and
lanes from [[wiki/angle-bank]] and [[wiki/audience-lanes]].

- Wearable before-and-after: pairs with the wearable-optimisers lane.
- Parent POV: pairs with [[campaigns/parents-kidzzz]].
- Wind-down routine: general-purpose, pairs well against
  [[companies/loftie]] comparisons.
- Physician explainer: uses [[people/dr-angela-holliday-bell]],
  [[people/dr-pedram-navab]] or [[people/dr-ed-omalley]].
- Debunk blue-light-glasses: an objection-handling format.
- Comparison against melatonin and sleep apps: pairs with
  [[campaigns/melatonin-quitters]].
- Unboxing and first night: pairs with any new-SKU launch.
- The 21 nights series: see [[wiki/the-21-nights-series]] for the dedicated
  three-touchpoint structure.
- Comparison against [[companies/hatch]], [[companies/loftie]],
  [[companies/therabody]] and [[companies/somnee]] directly.

[[sops/content-planner]] assigns a format to every calendar slot; no slot
should carry a hook without an assigned format from this list.

[[sops/ad-copywriter]] and [[sops/content-planner]] both reference this list
by name in their own SOPs, so a new format should be added here first before
either agent is expected to use it.
