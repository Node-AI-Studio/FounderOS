# Competitor Frame

How Helight frames itself against the four named bedside sleep competitors,
kept in one place so no two pieces of comparison content contradict each
other.

| Competitor | Their frame | Helight's counter |
|---|---|---|
| [[companies/hatch]] | All-in-one routine device, app-gated | Single-purpose protocol, no app |
| [[companies/loftie]] | Phone-replacement habit device | Physiological mechanism, not just substitution |
| [[companies/therabody]] | Worn recovery mask | Ambient, nothing worn |
| [[companies/somnee]] | Premium neurotech, app-personalised | Simple, one button, no account |

Every comparison stays on interaction model and evidence transparency,
never on disparaging a competitor's safety or effectiveness; see rule 14 in
[[wiki/claims-allowlist]]. This table is the intended source for the
storefront's compare page, currently empty (see
[[wiki/credibility-gaps-on-the-site]]), and for the comparison-against-
competitors format in [[wiki/format-playbook]].

[[sops/ad-copywriter]] checks new comparison copy against this table before
drafting, so the brand's public comparisons stay consistent across paid,
organic and on-site content.
