# Captions Style

Style rules for on-platform captions across TikTok, Meta and organic posts,
kept separate from the ad-copy rules in [[wiki/claims-allowlist]] since
captions are shorter and more casual but still fully subject to the same
claims discipline.

Lowercase, conversational tone, first sentence carries the hook from
[[writing/hook-vault]] with no preamble. No em dashes, no more than one
visual flourish (a single relevant symbol, used sparingly, never in paid
creative where platform norms differ). Every caption referencing a specific
claim (results timing, the guarantee, the patent) must match
[[wiki/claims-allowlist]] wording exactly, not a looser paraphrase.

Hashtag use is minimal and lane-specific rather than generic wellness tags,
since generic tags dilute reach without improving the [[wiki/audience-lanes]]
targeting the content is actually built for. [[sops/publisher]] checks
caption compliance as part of the final pre-post step, not a separate review.
